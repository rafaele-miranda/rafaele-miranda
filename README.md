## 🤖 AI Support Copilot — RAG over Product Documentation

Sistema inteligente de suporte desenvolvido para responder perguntas sobre produtos com base em uma base de documentação. O projeto utiliza **RAG (Retrieval-Augmented Generation)** para recuperar informações relevantes dos documentos antes de gerar uma resposta, fornecendo também as fontes utilizadas.

O objetivo é demonstrar, de forma prática, a construção de uma aplicação de IA **end-to-end**, combinando recuperação de informações, APIs e uma interface web.

**Features**:  

- 📚 Ingestão de documentação de produtos
- 🔎 Busca de informações utilizando **BM25**
- ✂️ Divisão dos documentos em chunks para recuperação
- 🤖 Geração de respostas utilizando LLM
- 📎 Retorno das citações utilizadas na resposta
- 🔄 Fallback local quando uma API de LLM não está configurada
- ❤️ Endpoint de health check
- 🌐 Interface web para interação com o assistente


**🛠️ Tecnologias**:

 Backend: 
- Python
- FastAPI
- LangChain
- BM25
- Pytest

Frontend:
- React
- JavaScript / TypeScript
- Vite

IA:
- RAG
- LLM
- Prompt Engineering
- Retrieval-based Question Answering

**Repositório**: [AI_Support_Copilot](https://github.com/rafaele-miranda/AI_Support_Copilot)


# 📦 Sistema de Empréstimo de Equipamentos

Sistema desktop desenvolvido em **Python** para gerenciamento de empréstimos de equipamentos.

O projeto permite cadastrar usuários e equipamentos, registrar empréstimos e devoluções e gerar relatórios em PDF. Foi desenvolvido com foco em **Programação Orientada a Objetos, organização de código e criação de uma aplicação desktop funcional**.

**Features**:

- 👤 Cadastro de usuários
- 📦 Cadastro de equipamentos
- 🔄 Registro de empréstimos
- ↩️ Registro de devoluções
- 🔁 Troca de equipamentos
- 📄 Geração de relatórios em PDF
- 🖥️ Interface gráfica desktop

**Tecnologias**:

- Python 3.10+
- CustomTkinter
- PDF generation
- Git
- PyInstaller

**Repositório**: [sistema-emprestimo](https://github.com/rafaele-miranda/sistema-emprestimo)
